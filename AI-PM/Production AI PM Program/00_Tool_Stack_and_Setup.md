# Tool Stack And Setup

The course teaches named tools deeply enough to be practical, but every tool is framed through durable PM principles: workflow modeling, context design, evals, cost, risk, and launch readiness.

---

## Core Path: No-Code / Low-Code

Learners should have access to:

- **Claude or ChatGPT** for product reasoning, structured outputs, system prompts, critique, and PRD drafting.
- **Perplexity or equivalent research tool** for source-backed market and competitor research.
- **Google Docs or Notion** for portfolio packet artifacts.
- **Google Sheets or Airtable** for golden datasets, eval tables, scoring rubrics, and simple cost models.
- **n8n** for workflow automation, tool calls, approvals, and agent demos.
- **Lovable, v0, Bolt, or equivalent** for lightweight UI prototyping.
- **Figma or FigJam** for flow maps, autonomy maps, system diagrams, and approval paths.

---

## Optional Advanced Path

For learners who want deeper technical credibility:

- OpenAI or Anthropic API access.
- Claude Code, Codex, Cursor, or similar AI coding environment.
- GitHub for private or public portfolio artifacts.
- LangSmith, Braintrust, Humanloop, or Langfuse for traces and evals.
- A hosted vector/RAG tool or lightweight framework.
- PostHog, Amplitude, or equivalent product analytics tool.

## Learner Setup Checklist

Before Week 1:

- [ ] Create or confirm access to Claude or ChatGPT.
- [ ] Create or confirm access to a research tool.
- [ ] Create a folder for portfolio docs.
- [ ] Create a spreadsheet for eval datasets.
- [ ] Create or confirm access to n8n.
- [ ] Create or confirm access to a no-code prototype tool.
- [ ] Decide whether to use a real work problem or the shared case.

Before Week 4:

- [ ] Confirm n8n access.
- [ ] Import or recreate the shared workflow skeleton.
- [ ] Confirm access to any APIs or mock tools used in the session.

Before Week 5:

- [ ] Prepare at least 10 candidate eval rows.
- [ ] Prepare one example trace or sample output from the prototype.

Before Week 8:

- [ ] Assemble final portfolio packet.
- [ ] Decide what can be public, private, or anonymized.
- [ ] Prepare a 2-minute executive narrative.

---

## Tool Principles

- Use tools to make product judgment visible.
- Start with spreadsheets for evals before moving to tracing platforms.
- Prefer simple workflows before agents.
- Add autonomy only when it improves measurable outcomes.
- Treat every tool action as a product permission decision.
- Keep tool choices replaceable.
