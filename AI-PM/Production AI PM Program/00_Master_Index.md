# Production AI PM Master Index

## What This Package Contains

This is the complete operating package for the Production AI PM cohort.

It includes:

- program positioning and structure;
- learner handbook;
- instructor delivery playbook;
- tool setup and advanced technical companion;
- weekly facilitator scripts;
- weekly learner workbooks;
- synced presenter and learner HTML decks;
- capstone casebook;
- assessment rubrics and certification criteria;
- prompt and workflow library;
- onboarding and communication templates;
- portfolio and career kit;
- marketing and landing page copy;
- premium add-on playbook;
- QA checklist and cohort tracker.

Use this file as the first internal reference when preparing the cohort.

## Weekly Folder Pattern

Each weekly folder contains:

- `W##_Facilitator_Script.md`
- `W##_Learner_Workbook.md`
- `W##_Presenter_Deck.html`
- `W##_Learner_Deck.html`

The presenter deck can open and sync with the learner deck for the same week.

---

## Recommended Setup Order

1. Read `00_Master_Index.md`.
2. Read `00_Cohort_Operating_Plan.md`.
3. Customize `00_Marketing_Landing_Page_And_Positioning.md`.
4. Set learner expectations using `00_Learner_Handbook.md`.
5. Send onboarding messages from `00_Onboarding_Communications_And_Email_Templates.md`.
6. Prepare the shared capstone case using `00_Capstone_Casebook.md`.
7. Run Week 1 using `W01_Facilitator_Script.md` and `W01_Presenter_Deck.html`.
8. Track progress in `00_Cohort_Tracker.csv`.
9. Score artifacts using `00_Assessment_Rubrics_And_Certification.md`.
10. Package final learner outcomes using `00_Portfolio_Showcase_And_Career_Kit.md`.

---

## What Is Complete

The package is complete for a first premium cohort if these are true:

- every weekly folder has a facilitator script, learner workbook, presenter deck, and learner deck;
- the learner handbook has been sent before Week 1;
- the tool setup doc has been sent before Week 1;
- the shared case has been prepared before Week 1;
- the cohort tracker has learner names and capstone tracks;
- rubrics are shared before the first submission;
- premium add-ons are defined before sales calls;
- the final portfolio packet is introduced in Week 1, not Week 8.

---

## What To Customize Before Launch

Customize these items before selling or running the cohort:

- cohort start date and schedule;
- pricing and tier names;
- cohort size;
- platform and community channel;
- tool access instructions;
- submission mechanism;
- feedback turnaround time;
- certificate language;
- examples from your own public products;
- privacy policy and terms for learner data.

Keep the curriculum logic stable. Customize the operational details.
