LLM map for CV rubric scoring

Models are positioned by estimated token cost for one compact CV assessment and an editable, provisional suitability score. The useful production zone is the upper-left: low cost, high recruiter-aligned scoring quality.

How to read it

  • X-axis: estimated USD cost per 1,000 CVs, displayed on a logarithmic scale. Assumes 2,200 input and 300 output tokens per CV.
  • Y-axis: provisional 0–10 suitability for evidence-grounded, rubric-based CV assessment. Replace these estimates with blind recruiter-benchmark results before any production decision.
  • Move the sliders to change the quadrant thresholds. Click a model marker to inspect its detail; use the legend to hide providers.
  • Costs exclude OCR, document parsing, retries, platform fees, storage, and any self-hosted compute.

Quadrant actions

  • Top-left: Scale now
  • Top-right: Selective upgrade
  • Bottom-left: Test / extract only
  • Bottom-right: Avoid or special case
