# Program QA And Launch Checklist

## Purpose

Use this checklist before launching or running a cohort.

It is meant to catch missing docs, broken links, unclear operations, and weak learner expectations before the cohort starts.

---

## Package Completeness

- [ ] `README.md` is current.
- [ ] `00_Master_Index.md` is current.
- [ ] Learner handbook exists.
- [ ] Tool setup doc exists.
- [ ] Advanced technical companion exists.
- [ ] Instructor delivery playbook exists.
- [ ] Assessment rubrics and certification criteria exist.
- [ ] Capstone casebook exists.
- [ ] Prompt and workflow library exists.
- [ ] Onboarding and email templates exist.
- [ ] Portfolio showcase and career kit exists.
- [ ] Marketing and landing page copy exists.
- [ ] Premium add-ons playbook exists.
- [ ] Cohort tracker exists.
- [ ] Local HTML navigator exists.

---

## Weekly Content QA

For each week:

- [ ] Facilitator script exists.
- [ ] Learner workbook exists.
- [ ] Presenter deck exists.
- [ ] Learner deck exists.
- [ ] Presenter deck opens the matching learner deck.
- [ ] Slide sync works.
- [ ] Workbook assignment matches the portfolio artifact.
- [ ] Facilitator script matches the 120-minute session format.
- [ ] No old branding or unrelated platform references.
- [ ] No unresolved placeholders.

---

## Learner Readiness

- [ ] Application or screening form is ready.
- [ ] Learner handbook is ready to send.
- [ ] Tool setup instructions are ready.
- [ ] Capstone selection instructions are ready.
- [ ] Portfolio packet template is ready.
- [ ] Confidentiality policy is communicated.
- [ ] AI use policy is communicated.
- [ ] Submission method is defined.
- [ ] Feedback turnaround time is defined.

---

## Instructor Readiness

- [ ] Instructor has reviewed all weekly scripts.
- [ ] Shared Customer Success Copilot case is prepared.
- [ ] Strong and weak sample artifacts are prepared.
- [ ] Critique norms are clear.
- [ ] Feedback template is ready.
- [ ] Parking lot location is ready.
- [ ] Attendance tracking is ready.
- [ ] TA role is defined, if applicable.

---

## Tool Readiness

- [ ] Video platform is selected.
- [ ] Recording policy is defined.
- [ ] Community channel is selected.
- [ ] Submission folder or LMS space is ready.
- [ ] Learner docs are shareable.
- [ ] Spreadsheet templates are shareable.
- [ ] n8n or workflow demo is ready.
- [ ] Backup screenshots or fallback demo exists.

---

## Sales And Marketing Readiness

- [ ] Landing page copy is customized.
- [ ] Application questions are finalized.
- [ ] Pricing and tiers are defined.
- [ ] Premium add-ons are defined.
- [ ] FAQ is ready.
- [ ] Refund, deferral, and cancellation policy is ready.
- [ ] Public examples are privacy-safe.
- [ ] Testimonials are requested only after real learner outcomes exist.

---

## Launch Week Checklist

- [ ] Send welcome email.
- [ ] Send setup checklist.
- [ ] Add learners to community.
- [ ] Share calendar invites.
- [ ] Share learner handbook.
- [ ] Share tool setup doc.
- [ ] Share portfolio packet template.
- [ ] Confirm capstone idea prompt.
- [ ] Test Week 1 decks.
- [ ] Prepare Week 1 critique examples.

---

## Post-Cohort Checklist

- [ ] Confirm completion criteria.
- [ ] Send certificates, if applicable.
- [ ] Send final portfolio polish plan.
- [ ] Request testimonials.
- [ ] Collect feedback survey.
- [ ] Review attendance and completion data.
- [ ] Identify weak sessions or artifacts.
- [ ] Update curriculum before next cohort.

---

## Final QA Rule

The program is ready to run when a learner can answer these before Week 1:

- What will I build?
- What tools do I need?
- What does good work look like?
- How will I get feedback?
- What will I leave with?

And the instructor can answer:

- What happens in every session?
- What is the shared case?
- What artifact is due each week?
- How will work be assessed?
- What does completion mean?
