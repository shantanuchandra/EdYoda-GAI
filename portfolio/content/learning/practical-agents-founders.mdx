## Shantanu Chandra Learning Lab

I created this practical overview for founders and operators. It is a Learning Lab path, not a claim that a paid course or learner account exists.

## Outcome

I help people decide when an agent is justified and design one with explicit tools, controls, and fallbacks.

## Launch modules

- Agent-vs-prompt test
- Tools and state
- Approval boundaries
- Production readiness

## How I teach it

I start with whether an agent is actually needed, then make tools, state, approval boundaries, and failure handling explicit before considering production use.
