Part 02
Get Hermes running

Do the wiring now. Build with it on Saturday.

01 / Install

Install Hermes

The installer handles its own Python, Node.js, and dependencies. You need Git already installed; Linux also needs curl and xz-utils.

curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash

On Windows, use PowerShell:

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

Open a fresh terminal when it completes, then verify:

hermes --version
02 / Model

Connect direct OpenAI API access

  1. Create an API key at platform.openai.com/api-keys.
  2. Add it to ~/.hermes/.env: OPENAI_API_KEY=sk-...
  3. Set your provider and model in ~/.hermes/config.yaml. The provider id is openai-api, not openai.
model: provider: "openai-api" default: "gpt-5.6-sol"
hermes model hermes status
03 / Telegram

Give your agent a remote-control channel

  1. Message @BotFather in Telegram and send /newbot. Keep the bot token it returns.
  2. Message @userinfobot or @get_id_bot to find your numeric Telegram user ID.
  3. Run the gateway setup and enter both values.
hermes gateway setup

Start it, leave it running, then message your bot: “Hello Hermes. Reply in one sentence and tell me what tools are active.”

hermes gateway
04 / Checkpoint

Confirm your agent is alive

Final test — send this exact message:

“Give me a one-paragraph setup report: model, tool route, channel, memory, and one thing still missing.”
Field notes
Common setup snags

Use the symptom to find the right fix.

hermes: command not found after install
Open a brand-new terminal window. The installer’s PATH update only becomes available in a fresh shell.
Install fails on macOS
First confirm Git is installed: git --version. On Apple Silicon, run softwareupdate --install-rosetta before retrying.
Provider not authenticated, or the OpenAI key is not used
Check ~/.hermes/.env for trailing spaces or quotes. Then confirm the provider is openai-api and the model is gpt-5.6-sol in ~/.hermes/config.yaml. Verify with hermes status.
SSL: CERTIFICATE_VERIFY_FAILED, an unknown issuer, or a self-signed certificate
A work, school, or VPN network may be inspecting HTTPS traffic, and Hermes does not trust that network’s certificate yet. Do not disable certificate verification. Switch to an unrestricted network if possible. Otherwise ask IT for the organisation CA certificate and add it through the approved Hermes/IT process. Restart Hermes and test in a new session.
API call failed after 3 retries: Connection error
Separate a network problem from a provider problem: confirm normal web access, then use hermes status to check the selected provider and model. On a managed network, resolve the certificate issue above before changing keys or reinstalling.
Hermes asks for a different provider or says a credential is exhausted
The active provider is unavailable, even if another key is present on your machine. Select the intended provider explicitly, verify it in hermes status, and use the approved credential for that provider. This workshop uses direct OpenAI API access.
A new chat works but an old chat still shows errors or outdated advice
Chats can retain the state from when they were created. After changing providers, credentials, or certificate settings, fully restart Hermes and start a new session. Keep the old chat as a record only.
Telegram does not respond
Re-run hermes gateway setup. Paste the bot token with no spaces, and make sure you used your numeric Telegram user ID rather than your username.
