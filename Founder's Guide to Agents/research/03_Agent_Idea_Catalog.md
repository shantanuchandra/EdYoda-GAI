# Founder Agent Idea Catalog — Round 2 Research

**Method:** 7-domain parallel fan-out research, each generating concrete named agent ideas (trigger / tools / autonomous action / why-agentic / feasibility / source), followed by adversarial concreteness+feasibility verification per idea (a skeptical judge agent scored each for being genuinely specific and buildable, not vague or hand-wavy).

**Result: 81 ideas collected across 7 domains → 51 survived verification.**

**Important reframing:** this research was originally scoped against **Make.com** feasibility (a no-code tool we later dropped in favor of **Hermes Agent**). The `feasibility` column below reflects the *original* Make.com judgment from the research pass — read it as a proxy for "this is a concretely wireable trigger → data → LLM → action chain," not literally about Make.com. Hermes supports webhooks, a cron scheduler, MCP servers, and 40+ tools, so most of these same shapes should port, but each one still needs a real Hermes-specific feasibility pass before being handed to founders as a guaranteed-buildable recipe. Treat this catalog as a **vetted idea bank**, not a Hermes build guide.

**Raw data:** full JSON (all 81 ideas + verdicts) preserved at [`raw_agent_catalog_round2.json`](raw_agent_catalog_round2.json).
